# D3D12-AliceTutorial — 10단계 이후 로드맵

## 목표
1~9단계(ClearScreen ~ ShadowMap)로 D3D12의 기본 파이프라인(디바이스/커맨드큐/디스크립터힙/펜스 동기화, 지오메트리, 텍스처, 라이팅, 노멀매핑, 스카이박스, 섀도우맵)을 다졌다. 이 문서는 10단계 이후 어떤 순서로 무엇을 추가할지 정리한다.

## 배경 / 결정 사항
- 참고 프로젝트 D3D11-AliceTutorial(`C:\Github\D3D11-AliceTutorial`)은 9단계 이후 메시 로딩(FBX/PMX), 애니메이션, PBR/IBL, 디퍼드 렌더링, 사운드 등 콘텐츠/에셋 파이프라인 쪽으로 37단계까지 확장했다.
- D3D12판은 지금까지 절차적 지오메트리(큐브/평면)만 사용하며 "저수준 파이프라인 학습"에 집중해왔다. 사용자와 논의 후, 10단계 이후에도 **D3D12 고유 기능 심화** 방향을 유지하기로 결정했다 — 메시/애니메이션 로딩 같은 콘텐츠 확장은 D3D11판과 차별화되지 않고, D3D12를 배우는 목적(저수준 아키텍처)에서 벗어난다.
- 캡스톤으로 DXR(DirectX Raytracing)을 포함하기로 결정했다. RTX 2000 이후 GPU에서 대부분 지원되며, D3D12의 대표적인 최신 기능이라 학습 가치가 높다.

## 로드맵 (10~16단계)

렌더링 품질 개선(10~13) → D3D12 아키텍처 심화(14~15) → 레이트레이싱 캡스톤(16) 순서로 구성한다.

| 단계 | 이름 | 핵심 내용 |
|---|---|---|
| 10 | MSAA | 멀티샘플 렌더타깃 + 리졸브. 플립모델 스왑체인은 직접 MSAA를 못 받으므로 별도 멀티샘플 RTV/DSV에 렌더링 후 백버퍼로 리졸브 |
| 11 | ComputeShader | 컴퓨트 파이프라인 최초 도입. 컴퓨트 기반 후처리(블러 등)로 사용법을 익힌다 |
| 12 | PostProcessing (HDR/Bloom/ToneMapping) | 오프스크린 HDR 렌더타깃 → 11단계 컴퓨트로 블룸 추출 → 톤매핑 후 백버퍼 출력 |
| 13 | PBR Materials | 기존 Blinn-Phong(6단계)을 Cook-Torrance 금속성/거칠기 기반 PBR로 교체. 16단계 DXR 반사에서 재사용 |
| 14 | Bindless Resources | SM6.6 동적 리소스 인덱싱(또는 대형 디스크립터 테이블)으로 머티리얼/텍스처 바인딩을 단순화. 디스크립터 힙 구조 학습 |
| 15 | Multi-threaded Rendering | 여러 워커 스레드가 각자 Command List에 씬 일부를 기록하고, 메인 스레드가 모아서 한 번에 `ExecuteCommandLists` 제출 |
| 16 | DXR Ray Tracing | 13단계 PBR 머티리얼 기반 레이트레이싱 섀도우/반사. 9단계 섀도우맵과 직접 비교 가능한 캡스톤 (RTX 계열 GPU 필요) |

### 순서를 정한 이유
- 10~13은 지금까지처럼 화면 결과가 계속 좋아지는 단계라 학습 동기가 유지된다.
- 14~15는 눈에 보이는 변화는 적지만 D3D12를 "제대로 쓰는" 아키텍처 패턴이라, 렌더링 기초가 갖춰진 뒤 배우는 게 자연스럽다.
- 16(DXR)은 13단계 PBR 머티리얼과 9단계 섀도우맵을 직접 비교/대체할 수 있어 캡스톤으로 가장 만족감이 크다.

## 범위 제외
- 메시 로딩(FBX/glTF/PMX), 스키닝 애니메이션, 사운드 등 콘텐츠 파이프라인 확장 — D3D11판과 차별화되지 않아 제외
- 디퍼드 렌더링, IBL — 필요성이 제기되면 16단계 이후 별도 로드맵으로 재검토

## 진행 방식
- 각 단계는 기존 관행대로 별도 브랜치(`10_MSAA`, `11_ComputeShader`, ...)에서 작업 후 PR을 생성하고 머지한다
- 커밋 메시지 접두사 `[feat]`/`[docs]`/`[chore]` 관행 유지
- 각 단계는 이전 단계 프로젝트를 복사해 확장하며, 루트 `README.md`의 바로가기 그리드와 단계별 `README.md`/`GUIDE.md`, `docs/images/`의 스크린샷 및 개념도(SVG)를 함께 추가한다
- 이 로드맵은 확정된 계획이 아니라 현재 시점의 기준선이다. 단계를 진행하며 필요에 따라 순서나 범위를 조정할 수 있다
